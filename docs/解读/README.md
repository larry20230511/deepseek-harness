# 解读

本目录是对本仓库（DeepSeek Harness fork）的阅读笔记，方便上手。

- **不是**产品正式文档，也**不会**自动进文档站。  
- 行为以根目录 `AGENTS.md`、`docs/architecture.md` 和各包 README 为准。

## 写作要求

写本目录文档时：

1. 用清晰易懂的简体中文；先结论，再表格或列表。
2. 避免仓库黑话；专有名词第一次出现时用白话说明「干什么」。
3. 表格侧重用途说明；路径、命令、包名保留原文，便于对照源码。
4. 与官方文档冲突时，以官方文档为准。
